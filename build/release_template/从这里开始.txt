记账中台 使用说明
========================================

它是干什么的
    接采集端（WxPushTool）推过来的微信消息 → 解析下注内容 → 记账 → 网页看板。
    不装 Python，双击就能用；数据留在本机，不上传。

----------------------------------------
第一次安装，按这个顺序走（顺序别反）

第 1 步：放好 EXE、双击打开
    把 MarkSixBot.exe 放到固定位置（比如 D:\MarkSixBot\），以后别删别挪。
    双击 → 弹出「记账中台」窗口。
    第一次启动会自动建配置：%LOCALAPPDATA%\MarkSixBot\config\server.json

第 2 步：填大模型 API Key（必须）
    「配置」页 →「大模型」那一行 → 填你自己的 Key（接口地址和模型名默认已填）。
    不填这个，点「启动服务」会提示「配置还没填」，服务起不来。
    填完点左下「保存配置」。

第 3 步：启动服务
    点「启动服务」，状态卡从「未运行」变成「运行中」。
    这时白名单还空着，状态栏会挂一句黄字：
        「白名单还没有启用的客户端：采集端现在推会被拒（401）」
    这是正常的 —— 下一步就是加它。服务本身、看板、手工记账这时都能用了。

第 4 步：白名单新增一条 API Key
    「白名单」页 →「新增」：
      微信号    ← 填采集端顶部「微信账号」那个号（形如 g18959290733）。
                  采集端那格右边有「复制」按钮，复制过来粘上就行。
      有效期至  ← 默认 9999-12-31（不限期）
      IP 白名单 ← 留空 = 谁都行；填了只收这些 IP
    点保存，Key 会自动进剪贴板（以后也能点那一行的「复制」重新取）。
    微信号必须与采集端顶部那个号一模一样，填错 = 采集端每次推送都回 401。

第 5 步：采集端
    1.「授权」页粘授权码 →「应用授权码」（没有授权码不能开始监听）
    2.「配置」页：
         推送地址 webhook ← 默认 http://127.0.0.1:8899/wx/hook（同机就用它）
         服务端 API Key  ← 粘第 4 步复制的那串 → 点「保存」
    3. 点「测试地址」：HTTP 200 就是通了；401 会把服务端拒收的原因直接写出来
    4.「监听对象」页默认已经是「全部会话」，直接点「开始监听」即可

第 6 步：采集端与服务端分开装在两台机器上
    采集端的「推送地址」改成 http://<服务端那台的局域网IP>:8899/wx/hook
    服务端那台要在 Windows 防火墙放行 8899 入站（第一次启动一般会弹窗，点「允许」）。

----------------------------------------
数据在哪
    %LOCALAPPDATA%\MarkSixBot\
        config\server.json          端口、大模型 Key、开奖时间
        config\wx_clients.json      白名单（微信号 + API Key + 有效期 + IP）
        data\state\<微信号>\        各号码累计、流水、已归档期次
        data\contacts\<微信号>.json 采集端上报的会话清单
        data\logs\bot_<日期>.log    运行日志
        data\backups\               每天自动备份
    换新版本只换 EXE，这个目录不动，账本不会丢。

----------------------------------------
控制台里能干的事
    「总览」 ：金额汇总、港澳号码盘、总额排序、最近记账（可撤销）
    「配置」 ：端口 / 大模型 Key / 开奖时间
    「消息」 ：每条消息的解析结果，可按期过滤
    「白名单」：采集端的 API Key 管理（新增 / 编辑 / 启用 / 停用 / 复制）
    底部按钮 ：启动服务 / 停止服务 / 保存配置 / 打开看板 / 打开日志
    手工记账、手工文本记账：顶栏入口，封盘后也能补记
    改配置后要「停止服务」→「启动服务」才生效。

----------------------------------------
开奖时间（封盘）
    「配置」页的「开奖时间」默认 21:30，每期一样。
    过了这个点本期不再收注（消息照收、照留痕，但不记账），次日 0 点自动进下一期。
    看板顶部会显示「还剩多久 / 已封盘」。
    手工记账、手工文本记账不受封盘限制。

----------------------------------------
出问题先看这三处
    1. 采集端点「测试地址」回 401：回执里的 reason 会直接说原因 ——
       不在白名单 / 已停用 / 有效期过 / 来源 IP 不在白名单 / 密钥对不上 /
       时间戳超窗 / 没带微信号。照它说的改，改完再测。
       最常见两种：白名单里填的微信号不是采集端那个号；两台机器时间差超过 5 分钟。
    2. 采集端推了但没记账：先去「消息」页看消息到没到。到了显示「未解析」，
       说明那句话里没号码/金额或写法太怪；没到就按上面第 1 条查 401。
    3. 状态卡一直「未运行」：多半端口被别的程序占了，换个端口，采集端地址跟着改。
       网页看板打不开但服务在跑：试 http://127.0.0.1:8899/ （端口可能改过）。
