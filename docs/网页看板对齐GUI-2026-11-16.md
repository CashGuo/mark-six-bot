# 网页看板对齐 GUI + 窗口自适应（2026-11-16）

## 目标

网页看板（`/` → `templates/dashboard.html`）与桌面控制台「总览」页**长得一样、功能一样**，
不多也不少；并且窗口变小不裁切（GUI 那份缩小后号码盘会被挤掉，网页先解决）。

## 数据口径：两份界面同一个函数算

新增 `GET /api/board`（`main.py`）：

- 全部数字走 `msb_view.summary()` —— 桌面控制台调的就是这个函数，所以**网页和 GUI 的数永远一致**；
- 一次给齐澳门 + 香港两本：`grids{MO,HK}`、`risks{MO,HK}`、`markets`、`zodiac_board{MO,HK}`；
- 带上消息流水（`/api/messages` 那一份，补了 `issue` 字段），网页靠它数「本期未解析」、列明细、点撤销；
- 带上账期选项（本期 / 前一期 / 前二期）与封盘字段（`draw_time` / `closed` / `seconds_left`）。

新增 `POST /api/board/reverse`：网页上的「撤销」。
控制台的 `/api/reverse` 要控制台令牌（令牌只在桌面进程里，网页拿不到），所以单开一个口子，
账务逻辑仍然是同一个 `reverse_record()`；依然只认本机来源（`/api/` 前缀在 `_guard_requests` 里已挡掉外部请求）。

## 页面结构（对着 GUI 一项一项抄）

| GUI 概览 | 网页 |
| --- | --- |
| 顶栏：总金额 + 本期 + 生肖年 + 号码盘 + 平特 + 本期已记账 + 本期未解析 + 账号下拉 | 一样，一行排开（窄窗口自动折行） |
| 左：澳门号码盘 / 香港号码盘（并排），最后一列下半截「本盘合计」 | 一样，两盘并排，第 6 列 2~12 行跨行放本盘合计 |
| 中：平特 —— 澳门/香港各 12 生肖格 + 右侧紧接「合计」 | 一样 |
| 中右：组合注竖栏，内容滚动、合计钉在右下角 | 一样 |
| 下：最近记账 —— 账期下拉 + 「消息记账 N 笔（测试·已撤）· 账目 M 笔（手工）」+ 8 列表格（含撤销） | 一样 |
| 右：澳门总额排序、香港总额排序（序/号码/生肖/金额/占比） | 一样，上下两本 |

**删掉的（GUI 没有，属于「多」）**：监听对象整块（搜索/勾选/保存并下发）、未解析独立表格、
模型/验签/服务器时间那行、备份清空提示、页面大标题、刷新按钮、底部说明。

**保留的**：顶栏右端「手工记账」入口（跳 `/manual`，新标签页打开）、账号下拉、
以及「本期未解析」点一下跳到消息页（消息页 6 列：时间/账号/会话/发送人/内容/结果，与 GUI「消息」页对齐）。

> 一处已知差异：顶栏本期后面的「21:30 截止（剩…）/ 已封盘」是网页独有的
> （封盘功能当初只要求做到看板上，GUI 顶栏没有这一句）。要 GUI 也有的话另说。

## 自适应

三档断点，靠 CSS 变量 `clamp()` 缩放字号与格子：

- **≥1180px**：左列（双盘 + 平特 + 记账）+ 右列（两本排序），与 GUI 宽屏排布一致；
- **<1180px**：右列落到下面，两榜并排；号码盘仍左右并排；
- **<860px**：全部单列 —— 澳门盘、香港盘上下排，盘面 6 列自适应宽度，**不裁切**；
  平特的生肖格与组合注也上下排。

号码盘每一格的 `grid-row / grid-column` 是写死的，不靠自动流：
第 6 列被「本盘合计」占住后，自动流会把后面的格子顶前一位，整盘错行（踩过一次，截图可复现）。

金额紧跟号码（不再 `margin-left:auto`），与 GUI 一致 —— 否则格子一宽，金额甩到右边，看着像两栏。

## 实测

隔离实例（`%TEMP%\msb_board`，8936 端口，复制了一份真实账本再补两笔造的数据）：

| 项 | 结果 |
| --- | --- |
| `/api/board` | `ok`，总金额 10810、号码盘 8 个号、平特 10000、已记账 3、澳门 10390 / 香港 420，grids 12 行（马行 5 格）、risks 5 / 3 条 |
| 宽屏 1920 | 顶栏一行齐、双盘并排、本盘合计在第 6 列中部、右列两榜、平特两行、记账 8 列 |
| 窄屏 792 / 559 | 单列堆叠，两盘完整、合计可见，无横向裁切 |
| 撤销 `board-a-0002`（01 100 / 13 200） | 返回 `ok`；总金额 10810→10510；澳门 10390→10090；有注号 8→6；已记账 3→2；该行在列表里变「已撤销」 |
| 点「本期未解析」 | 切到消息页（切视图时滚回顶部），显示本期 12 条、未解析 0 条；行内可撤销 |

## 注意

- 改动是 `main.py`（两个新接口）+ `templates/dashboard.html`（整页重写）。
- **已打包的 exe 不含这些**，要出客户版本得重新编译。
- 正在跑的服务进程读的是旧模板（Jinja 在非 debug 下缓存模板），**必须重启服务**才看得到新看板。
