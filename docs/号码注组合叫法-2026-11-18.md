# 号码注组合叫法：支持范围与实测（2026-11-18）

## 1. 起因

客户真实报单：

```
香47，49各250，30买100，19买50
```

规则解析失败，整条判「规则解析不了」，只能送大模型兜底。逐段试出来的结果：

| 段 | 修复前 | 原因 |
|---|---|---|
| `49各250` | ✓ `{49: 250}` | — |
| `香47` | ✓ `{47: 10}` | 单号不写金额，按默认 10（既有行为） |
| `30买100` | ✗ `30100` | 号码和金额被黏成一串 |
| `19买50` | ✗ `1950` | 同上 |
| 整条 | ✗ | 一段失败 → 整条失败 |

## 2. 根因

`normalize()` 里原来无条件删掉格式词：

```python
for w in ("下注", "买", "叫"):
    t = t.replace(w, "")
```

这条规则本意是「买鼠50 / 下注鼠50」——格式词写在**对象前面**时是纯噪声。但客户也写
「30**买**100」，那个「买」是动词，一删就变成 `30100`，号码和金额黏死。

改成**只剥项首**的（前面是行首或分隔符，且后面紧跟中文）：

```python
t = re.sub(r"(?:^|(?<=[\s,，、;；/|]))(?:下注|买|叫)(?=[\u4e00-\u9fff])", "", t)
```

同时把单价词表抽成 `_AMOUNT_WORDS`（`_PRICE` 与 `_HAS_PRICE` 共用，以前是两份内联
正则，改一处漏一处），并补上客户实际会用的动词与符号。

## 3. 现在认的写法（全部实测通过）

### 3.1 号码 + 动词 + 金额（单号）

`30`+动词+`100`，结果一律 `{30: 100}`：

| 动词 | 例子 | 备注 |
|---|---|---|
| 各 / 个 / 号 | `30各100` `30个100` `30号100` | 既有 |
| 买 / 打 / 要 / 投 / 押 | `30买100` `30打200` `30要50` `30投30` `30押100` | 本次新增（买之前被误删） |
| 跟 / 落 / 记 / 报 / 叫 | `30跟50` `30落20` `30记100` `30报30` | 本次新增 |
| = ≈ × @ * | `30=100` `30×100` `30@100` `30*100` | 本次新增 |

金额写法：

- 阿拉伯：`30买100`
- 中文：`30买一百` `19买五十`
- 带单位：`30买100元` `30买100块` `30买100蚊`（粤语「蚊」当元）

### 3.2 多个号码 + 一个金额

`30、31各100` / `30/31买100` / `30 31 32各50` / `49、30买100`
→ 每个号都给这个金额（`30、31各100` = 30 各100 + 31 各100，共 200）。

### 3.3 连接词（当「和」讲）

`30同31各100`、`30和31各100`、`30跟31各100`、`30及31各100`、`30与31各100`、
`30加31各100`、`30、31同100` → 都是「30 和 31 各 100」。

「跟」两边都是号码时当连接词；`30跟100` 这种后面是金额（>49）的仍是动词。

### 3.4 号码范围

`1-10各10`、`1至10各10`、`3~7各5` → 展开成逐个号，各 10。
只展开像号码的（1~49、升序、跨度 ≤ 20），别的连字符原样留着。

### 3.5 空格与点号

| 写法 | 说明 |
|---|---|
| `30 买 100` | 号码和动词之间夹空格，先紧缩再解析 |
| `30买100 31买50` | 空格分隔两注（既有） |
| `30买100;31买50` | 分号分隔（既有） |
| `30买100.31买50` | 点号续写下一注；只认「两位以上金额 + 点 + 号码 + 动词」，不碰 3.5 这种小数 |

### 3.6 跟波色 / 单双 / 生肖混排

| 写法 | 结果 |
|---|---|
| `红波30` | 红波 17 个号各 30，共 510（金额没动词也认，号码最大 49） |
| `红波30，47买100` | 510 + 100 = 610 |
| `香47，49各250，30买100，19买50，红波30` | 650 + 510 = 1160；30、19 同时又在红波里，**金额累加**（30→130、19→80） |
| `小单50 30买100` | 小单 12 号各 50（600）+ 30 各100 = 700 |
| `鼠50 30买100` | 鼠 4 号各 50（200）+ 30 各100 = 300 |
| `红波30 鼠各50` | 红波 510 + 鼠 200 = 710 |

### 3.7 前缀式（保持既有行为）

`买鼠50`、`叫鼠50`、`下注鼠50` → 前缀直接剥掉，鼠 4 号各 50。

## 4. 仍然不认（4 条，判死而不是猜）

| 写法 | 为什么不认 |
|---|---|
| `30买一旧水` | 粤语俚语「一旧水」=100 元，不是数字，规则不认 |
| `30蚊100` | 「30蚊」可以指钱（30 元）也可以指号，语义不明 |
| `30买100倍` | 倍数写法，金额到底多少不明 |
| `30元100` | 同上，语义不明 |

这四条都会判失败，走大模型兜底或让客户换写法。要支持的话告诉我准确含义。

## 6. 需要你确认的语义（现有行为，怕理解偏）

1. **`香47` 这种只写号码不写金额** → 按默认 **10 元**记（47 号 10 元）。客户是这个意思吗？
2. **裸生肖 `鼠50` / `鼠各50`** → 记「鼠的 4 个号各 50」（进号码盘，4 个号），不是「平特鼠」整笔。
3. **`红波30`** → 红波 17 个号**每个** 30，共 510（不是整笔 30）。
4. **多号连写带一个金额** `49、30买100` → 两个号**各** 100（共 200），不是「49 默认 10 + 30 买 100」。
5. **同号重复报** `47各250 47各250` → 累加 500（与去重窗口是两回事：30 秒内同人同正文才算重发）。

## 7. 改动清单

`bet_rules.py`：

| 位置 | 改动 |
|---|---|
| `normalize()` | `下注/买/叫` 只剥项首（前面是行首或分隔符、后面跟中文） |
| `normalize()` | 号码与动词之间空格紧缩（`30 买 100`） |
| `normalize()` | 连接词 `同/和/跟/及/与/加/同埋`（两边都是号码时当「和」） |
| `normalize()` | 号码范围展开（`1-10` `1至10` `3~7`） |
| `normalize()` | 点号续写（`100.31买`） |
| `_AMOUNT_WORDS`（新增常量） | 各/各号/各码/各数/个/号/买/打/要/投/押/跟/落/记/报/同/叫/约/=/≈/×/@/* |
| `_PRICE`、`_HAS_PRICE` | 改为引用 `_AMOUNT_WORDS`，保证切项与取价口径一致 |
| `_subject_money()`（新增） | 上一段是「生肖+金额且金额>49」时，后面起号码注就断开 |
| `split_items()` | 末尾那段自带单价时独立成项（否则会被并回上一项） |

注意：`_AMOUNT_WORDS` 里**故意没有「中」** —— 组合注是「二中二100」，那个「中」要先给
`_ZHONG_WORDS` 认，加进来会抢走。
